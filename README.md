# 课程学习知识库模板

一套面向 **Obsidian + AI 协作** 的跨学科课程学习模板。把教材 PDF、教师 PPT、课堂录音三类材料，整理成**每个结论都能回到原始位置**的知识库。

它不追求让 AI 生成大量笔记；它追求的是一年后你还能回答：「这句话出自教材哪一页、哪张幻灯片、录音第几分钟？」

> 本仓库是模板本体，不含任何真实课程材料。复制后替换 `AGENTS.md` 第 0 节的课程信息即可开课。

**别人怎么用：** 点仓库右上角的 **Use this template** → 得到一个干净的、属于你自己的仓库（不含本模板的提交历史）→ 按下面第五节填空开课。不想用 GitHub 的话，直接复制文件夹也行。

---

## 一、它想解决的问题

一次课的真相分散在三种材料里，而且三者经常不一致：

| 材料 | 提供什么 | 天然缺陷 |
|---|---|---|
| 教材 | 学科结构、定义、图表、系统上下文 | 印刷页 ≠ PDF 页；图与表格里的限定条件检索不到 |
| 教师 PPT | 课堂实际展示的顺序与侧重 | 只有骨架，没有口头解释和更正 |
| 课堂录音 | 口头解释、答疑、补充和更正 | 不可检索；自动转写会错专业名词 |

常见的失败模式是：AI 一次性生成一份「课堂总结」，把教材原话、教师口述、模型常识搅在一起，读起来很顺，但**无法回查、无法纠错、无法迁移**。

这套框架用「分工 + 编号 + 状态词」把这件事拆开，让每一层只干一件事，且每件事都可验证。

## 二、设计哲学

### 1. 定位、比较、核对 —— 而不是扩写

AI 在这套框架里的职责是**定位、比较、解释、核对**，不是自动扩写整本教材。

对应到流程上：不生成整课摘要、不生成考试重点、不因为某个主题出现多次就宣布「必考」。真正的学习动作（读原文、回答问题、纠正自己的理解）留给人。

### 2. 四类信息永不混同

同一个结论可能有四种性质完全不同的来源，它们必须分开表述：

```
原始资料（raw/ 原件）
  ├─ 自动转写（lessons/Lxx-转写.md，可重建的阅读副本）
  ├─ 个人理解（wiki/，经过自己组织）
  └─ AI 推断（候选，未经核对）
```

推论：

- 自动提取文本与其原 PDF 属于**同一来源**，不能当成两份独立证据互相印证。
- 转写里读起来通顺 ≠ 正确；数字、单位、否定词、专有名词、专业术语是优先核对对象。
- **不把 AI 猜测覆盖进原文**。转写里的专业词疑点，在课堂页另记「原词 / 候选正确词 / 依据 / 核对状态」。
- 不把「AI 的常识」写成「教师强调」。

### 3. 每条重要结论都能回到「文件 + 位置」

位置不是模糊的「教材里有」，而是：

- **印刷书页** 与 **PDF 页码** 分开记 —— 扫描件含封面、前言、空白页或缺页，偏移量只有核对后才能用，不假设全书固定相差同一数值
- **PPT 文件 + 幻灯片页**
- **音频起止时间**，以及可跳转的字幕段

没有提供的页面只登记缺口，**不生成虚假跳转链接**。

### 4. 分工唯一，不重复抄写

同一个信息只在一个地方维护，其他地方只引用：

| 层 | 文件 | 只负责 | 明确不做 |
|---|---|---|---|
| 入口层 | `index.md` | 教材从哪进、有哪些课堂材料、有哪些值得反复看的笔记 | 不放整课摘要，不复制教材目录 |
| 定位层 | `教材导航.md` `知识点.md` `PPT导航/` | 章节 → 页码；K 编号 → 页码；幻灯片 → K 编号 | 不重写知识点名称，不做内容总结 |
| 对齐层 | `lessons/Lxx.md` | 一次课的材料对应关系（**唯一**维护位置） | 不生成摘要，不当笔记用 |
| 理解层 | `wiki/` | 跨课反复用到的机制、易混概念、鉴别思路 | 不预设子目录，不建「我的错题」 |

首页只链接课堂页；知识笔记只引用片段。跨源查询（「K07 都在哪出现」）当场搜索汇总，不做手工汇总表。

### 5. 稳定的编号主干

`知识点.md` 是知识点编号（`K01`…）的**唯一来源**。

- 连续分配，**追加不重排**，删除后**不回收编号** —— 否则旧引用会指向另一个知识点。
- 其他文件（教材导航、PPT 导航、课堂页对齐表）只引用 `K` 编号，不重写名称。
- 编号让三份独立的导航（教材 / 课件 / 录音）能互相对账，而不各自发明一套叫法。

### 6. 候选 / 已核对：把不确定性写进状态里

全库统一的状态词表：

| 状态 | 含义 | 谁能写 |
|---|---|---|
| `候选` `候选对应` | 由目录、关键词或脚本线索得到的**可能**位置 | AI 可以写 |
| `已核对` | 已回看原件页面或回听录音确认，**并写明依据** | 只有核对之后 |
| `未命中` | 按名称与别名检索后确实没找到，如实保留 | AI 可以写 |
| `待核对` | 已登记但尚未验证 | AI 可以写 |
| `待补` | 已知存在但材料缺失 | AI 可以写 |
| `未收到` | 原件尚未进入 `raw/` | AI 可以写 |

关键约束：**脚本命中、关键词匹配、AI 推断都不能升为「已核对」。**

「不知道」是被允许并且被保留的状态。不猜、不补全、不用推测填满表格 —— 空白本身就是信息。

### 7. 按需生长，而不是按模板补全

> 先有实际问题，再决定是否记录；先有实际材料，再建立对应记录。

- **没有内容，就不预建分类、模板和索引。** 只有教材时，就只建 `index.md` 和 `教材导航.md`。
- 新增任何文件前先问：**它具体减少了哪一步查找、重复记录或复习的成本？** 说不清就暂时不建。
- `wiki/` 不预设子目录，用具体标题和链接组织，只有实际查找困难时才调整。
- 不为「整理完成」硬填表格；没有疑问就省略「疑问与纠错」一节。

这条原则同样适用于整个框架：**如果某个部分增加的维护成本已经超过学习收益，就合并或取消它。**

### 8. 材料原件只读

`raw/` 是原件区，**不修改、不移动、不改名、不覆盖**。

- `raw/md/`（教材转换副本）与 `lessons/Lxx-转写.md`（字幕阅读页）是明确标注的**可重建副本**，不是新的独立来源，也不在这里维护个人总结。
- 引用仍然回到原件；重建转写页后要复核原有段落引用。
- 课件更新时保留版本区别，**不覆盖后假装旧的页码仍然有效**。

### 9. 医学边界与隐私

- 课程材料**不能自动等同于当前临床建议**。涉及诊疗、用药剂量、临床规范时，另行核对适用情境与现行依据。
- 录音可能包含同学发言或病例信息。涉及可识别个人信息时，**不因为接入 AI 就默认允许上传到外部服务**。

## 三、目录结构

```text
课程文件夹/
├── index.md                日常首页（唯一入口）
├── 教材导航.md             章节 → 印刷书页 → PDF 文件 → PDF 页
├── 知识点.md               K 编号的唯一来源
├── PPT导航/<课件名>.md      幻灯片 → K 编号
├── raw/                    原件区（只读，见下方版权说明）
│   ├── PDF/                教材 PDF
│   ├── md/                 可选的教材转换副本（保留配图与页码映射）
│   ├── 目录/               目录照片，有需要才保留
│   ├── PPT/                教师发放的课件原件
│   └── recordings/Lxx/     原始音频 + 原始字幕
├── lessons/                Lxx.md（课堂页，对齐关系唯一维护处）＋ Lxx-转写.md（自动生成）
├── wiki/                   按需建立的长期知识笔记，不分类
├── scripts/                辅助工具与测试（清单见 scripts/README.md）
├── .claude/skills/         流程 skill（教材 / PPT / 对齐 / 检索）
├── .pi/settings.json       让 pi 也读取 .claude/skills，规则只保留一份
├── AGENTS.md               AI 工作规范唯一正文
├── CLAUDE.md               对应工具时的简短入口，只指向 AGENTS.md
├── log.md                  简短变更记录，不是学习入口
└── 医学课程学习框架说明.md  来源参考文档，不参与检索
```

## 四、AI 协作：三个流程 skill

规则只写在 `.claude/skills/` 一处，`.pi/settings.json` 把该目录接给 pi，不复制第二份。

| Skill | 触发 | 产出 | 硬约束 |
|---|---|---|---|
| `textbook-knowledge-map` | 要按知识点学某一章 | `知识点.md` 新增 K 条目、`教材导航.md` 的 K 范围 | 按章增量，不做整本生成 |
| `ppt-knowledge-map` | 收到新课件 | `PPT导航/<课件名>.md` | 一份 PPT 一个导航文件 |
| `lesson-align` | 收到录音 + SRT | `lessons/Lxx.md` 的主题对齐表 | 一次课一行；脚本只给候选 |
| `paper-search-advisor` | 启动课题 / 文献综述 | 分层检索词、数据库顺序、检索式 | 与课程材料分开，不写入课堂页 |

顺序约束：**`知识点.md` 先有（至少本章）→ PPT 导航 → 录音对齐。** 缺前置就先建前置，不跳过直接猜编号。

`scripts/` 只做重复、可验证的机械操作，三个脚本对应三个 skill 的机械化部分：`import_srt.py`（SRT → 转写页）、`extract_slides.py`（.pptx 逐页文字与备注，标准库实现）、`find_terms.py`（按术语找候选时间段）。

它们**都不**检查音频总时长、不识别音频内容、不判断讲解内容、不做教材或 PPT 对齐。输出一律是候选。

```powershell
python -B -X utf8 -m unittest discover -s scripts -p "test_*.py"
```

## 五、30 秒上手

1. 复制整个文件夹，改名为课程名。
2. 替换 `AGENTS.md` 第 0 节的课程信息；清空 `index.md`、`log.md` 里的示例行（保留结构）。
3. 放入实际已有的教材 → 建立 `教材导航.md` 与 `index.md` 的材料状态。
4. 录音、PPT 到达后按 `AGENTS.md` 2.1 的「按材料类型的处理链」逐项补；`L01`… 编号分配后不重排、不回收。
5. 检查：**能否从 `index.md` 走到已有材料？页码与时间是否可回查？未知状态是否被如实保留？**

新课程必须独立核对，**不能沿用其他课程的检查结论**。

## 六、Obsidian 配置与推荐插件

本仓库**不提交插件本体**（构建产物体积大、可从社区市场重装），只保留插件清单 `.obsidian/community-plugins.json`。克隆后按清单自行安装即可。

| 插件 | 作用 | 必需性 |
|---|---|---|
| [Dataview](https://github.com/blacksmithgu/obsidian-dataview) | 按 frontmatter 查询笔记 | 可选，`wiki/` 笔记的 frontmatter 用得上 |
| [Smart Connections](https://github.com/brianpetro/obsidian-smart-connections) | 语义相近笔记推荐 | 可选 |
| [BRAT](https://github.com/TfTHacker/obsidian42-brat) | 安装未上架插件 | 仅当用 claudian 时 |
| [Claudian](https://github.com/YishenTu/claudian) | 在 Obsidian 内调用 AI | 可选；不用 AI 协作时整套 `.claude/` 可以不管 |

> 文件名字里的 `[[双链]]` 只在 Obsidian 内可跳转；在 GitHub 上只能当普通文本看。这是本模板的一个已知取舍：**检索定位依赖 Obsidian，版本管理与对外展示依赖 Git。**

## 七、第三方内容与版权

本模板 **不包含任何真实课程材料**。`raw/` 下只有 `.gitkeep` 占位。

### 未随仓库分发的内容

| 内容 | 原因 | 如何获取 |
|---|---|---|
| `.claude/obsidian-skills-main/` | 上游第三方项目（MIT，[kepano/obsidian-skills](https://github.com/kepano/obsidian-skills)），不适合 vendored 进本模板 | `npx skills add git@github.com:kepano/obsidian-skills.git` 或 `/plugin marketplace add kepano/obsidian-skills` |
| `.obsidian/plugins/` | Obsidian 社区插件的构建产物，非本模板内容 | 从社区插件市场安装，清单见上一节 |
| `.claudian/`、`.claude/settings.local.json` 等 | 本机工具状态与会话记录 | 各自重新生成 |

`.claude/skills/` 下的四个 skill（`textbook-knowledge-map`、`ppt-knowledge-map`、`lesson-align`、`paper-search-advisor`）为本模板自有内容，随仓库分发，适用本仓库的 MIT 许可。

### 使用本模板建立自己的课程库时

- 教材 PDF、教师 PPT、课堂录音通常**受版权保护**，公开发布可能构成侵权。
- 课堂录音可能包含**同学发言、病例等可识别个人信息**。
- `.gitignore` 里已备好对应开关：填入真实材料时，解除 `raw/**` 两行注释，让材料只留在本地。
- 若公开自己的课程库，应同时删除模板中的示例占位内容，并自行评估材料授权范围。
