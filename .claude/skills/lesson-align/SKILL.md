# 录音 / 字幕 / 知识点对齐

开工前完整读取 `AGENTS.md`。核心原则：脚本给的是候选，人回听过的才算已核对；不承诺音频跳秒。

## 什么时候用

- 用户说「这节课对一下知识点」「把录音和字幕对到 K 编号上」。
- 一次课做一次，结果只写进 `lessons/Lxx.md`，不在别处再抄一张对齐表。

## 步骤

1. **检查素材**：`raw/recordings/Lxx/` 下的音频与 SRT。
   - 缺 SRT：只登记音频状态，说明「没有字幕无法生成可搜索转写」，停下等用户决定。
   - 缺音频但有 SRT：可以生成转写页，但要在课堂页注明录音未收到，时间轴无法回听验证。
2. **确认转写页**：`lessons/Lxx-转写.md` 存在且时间轴可用；没有就先运行
   ```powershell
   python -B -X utf8 scripts/import_srt.py --lesson L01 --srt "raw/recordings/L01/原始字幕.srt" --audio "raw/recordings/L01/原始音频.m4a"
   ```
   转写页是自动生成内容，**不手工修改**；要更新就重新生成并复核原有段落引用。
3. **首次使用该课录音时**，抽查音文是否对齐：开头、中间、结尾各挑一段回听，把抽样范围与结论写进课堂页「录音核对」。**不能沿用其他课程的检查结论。**
4. **确定本次课的 K 编号**：优先看 `PPT导航/<课件名>.md` 和教材进度，用户给出的范围最优先。一行一个 K 编号；一个知识点跨多次课，就在各次课里各写一行。
5. **找候选位置**：
   ```powershell
   python -B -X utf8 scripts/find_terms.py --lesson L01 --terms "房室结,房室束,传导系统" --merge-gap 120
   ```
   - 用知识点名称 + 教材原词 + 课堂叫法（写在 `知识点.md` 别名列）分别搜。
   - 命中 0 段：换更短的词或别名再试；仍无命中就如实写「未命中」，**不按 PPT 顺序推断时间**。
   - 术语有字间空格噪声时脚本已默认容错；需要严格匹配才加 `--exact`。
6. **判断候选区间**：相邻知识点的区间重叠时，说明「同段落讲了两者」；明显是回顾、答疑、串讲的片段单独标注，不要塞进该知识点的正式位置。
7. **写入 `lessons/Lxx.md`**：原始材料（日期、教师、教材/PPT/音频/SRT 状态、转写入口）、主题对齐表、疑问与纠错、录音核对。没有内容的段落直接省略。
8. 更新 `index.md` 课堂材料表（转写、PPT 列）与 `log.md`（一行：`align | L01 对齐 K07–K12`）。
9. 向用户报告：已对齐知识点、未命中的知识点、标为候选的行、需要回听的片段。

## 课堂页对齐表

| 主题或问题 | 教材位置 | PPT 位置 | 录音与转写位置 | 核对状态 |
|---|---|---|---|---|
| K07 心脏传导系统 | 第 3 章 p.123 / PDF p.131 | [[PPT导航/L02-心脏]] p.2–5 | 00:12:30–00:18:40，[[lessons/L01-转写#^s0031]] | 候选对应 |
| K08 传导顺序 | 同上 p.125 | 同上 p.6 | 未命中 | 待核对 |

- 「教材位置」「PPT 位置」写文件/页/幻灯片，不重复粘贴知识点名称与解释。
- 引用字幕段用 `[[lessons/L01-转写#^s0031]]`；**这只跳到文字段落，不代表播放器会跳到相同秒数**。
- 状态写法：
  - `候选对应` — 由脚本或关键词线索得到，尚未回听
  - `已核对（回听 00:12:30–00:14:10，教师原话「…」）` — 只有回听/回看原件后才能这样写
  - `未命中` / `待核对` — 如实保留未知

## 硬规则

- 不修改 `lessons/Lxx-转写.md` 与 `raw/` 下的任何文件；转写里的专业词疑点在课堂页记「原词 / 候选正确词 / 依据 / 核对状态」。
- 不把 AI 猜测当成教师说法，也不因为脚本命中就宣布「讲过这个知识点」。
- 不生成整课摘要、不生成考试重点判断；不把对话过程原样搬进课堂页。
- 对齐表只在这里维护一份；知识笔记只引用相关片段。

## 完成后检查

- 每行是否有可回查的位置（文件 + 页 / 幻灯片 / 时间范围）？
- 是否存在没有依据的 `已核对`？有就退回 `候选对应`。
- 未命中的知识点是否如实保留，而不是留空或硬填？
- 首页是否只增加了链接与状态，没有再抄一份对齐表？
