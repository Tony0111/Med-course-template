# PPT 知识点导航

开工前完整读取 `AGENTS.md`。PPT 是原件，只读；导航文件是派生出来的定位层。

## 什么时候用

- 用户说「这份 PPT 做个导航」「把课件对到知识点上」。
- 一份 PPT 只建一个 `PPT导航/<课件名>.md`；同一课件跨多次课时，课堂页引用同一份，不复制。

## 步骤

1. 确认原件位置与文件名（含版本），例如 `raw/PPT/L02-心脏.pptx`。不改名、不移动、不覆盖旧版本。
2. 读 `知识点.md`，拿到已有 K 编号与名称；`PPT导航/` 下已有同名文件时先读它，做增量更新而不是重建。
3. 提取页面文字：
   - `.pptx`：
     ```powershell
     python -B -X utf8 scripts/extract_slides.py "raw/PPT/L02-心脏.pptx" --list
     python -B -X utf8 scripts/extract_slides.py "raw/PPT/L02-心脏.pptx" --slides 1-20
     ```
     先 `--list` 看整体，再按段读全文。**不要一次把整份课件倒进上下文。**
   - `.pdf`：直接按页阅读原文件。
   - 其他格式：说明无法读取，请用户提供 pptx 或 pdf；不要凭文件名猜内容。
4. 逐页映射到 K 编号：
   - 一页对应多个知识点就都写上（用逗号分隔）。
   - 封面、目录、致谢、练习页写 `—`。
   - 纯图页、只有关键词的页、标题与教材说法不一致的页：回看原件再判断，判断不了的记进「未映射 / 待确认」，**不凭标题猜**。
5. 新知识点追加到 `知识点.md`，状态 `候选`，备注写 `来自 raw/PPT/<文件名> p.N，待与教材核对`。
6. 写 `PPT导航/<课件名>.md`（格式见下）。
7. 更新 `index.md` 课堂材料表的 PPT 列（文件名 + 页数），并在「已有笔记」之外不新增索引。
8. 在 `log.md` 追加一行：`## [YYYY-MM-DD] ingest | <课件名> PPT 导航 — N 页，映射 M 个知识点`。
9. 向用户报告：已映射页数、未映射页、标为猜测的判断、需要回看原件的页。

## 导航文件格式

```markdown
---
type: ppt-navigation
title: L02-心脏 导航
course: <课程名称>
file: raw/PPT/L02-心脏.pptx
slides: 42
updated: 2026-09-15
---

# L02-心脏 导航

> 源侧映射：幻灯片 → 知识点编号。本页只做定位，不写讲解摘要。
> 课堂页只引用本页并补录音时间，不再重复抄写幻灯片标题。
> 对应原件：`raw/PPT/L02-心脏.pptx`，本页页码按该版本计；课件换版本要更新本页，而不是假设旧页码仍有效。

## 幻灯片映射

| 幻灯片 | 页面内容（原件标题） | 知识点 | 状态 |
|---|---|---|---|
| 1 | 课程与教师 | —（封面） | — |
| 2 | 心脏传导系统 | K07 | 候选 |
| 3 | 传导顺序（图） | K07, K08 | 候选（图需回看原件） |

## 未映射 / 待确认

- <只有图片没有文字的页；标题与教材不一致；版本信息缺失等>
```

## 硬规则

- 不把幻灯片内容改写成摘要、不做「重点标注」；导航只回答「哪个知识点在第几页」。
- 不复制原件到其他目录，不转换出第二份课件；`raw/PPT/` 里的旧版本保留区别。
- 状态只有 `候选` 与 `已核对`；`已核对` 要写明核对了什么（如 `核对原件 p.3 图注`）。
- 文字提取不含图片与版式：图表、流程、表格位置必须回看原件，读取路径不等于看过内容。

## 完成后检查

- 每页是否都有映射或明确的「未映射」记录？页数是否与原件一致？
- 新登记的知识点是否都标了候选来源？
- 是否出现了把 PPT 内容大段抄进导航文件的段落？有就删。
- `index.md` 的 PPT 列是否更新为实际文件名与页数？
