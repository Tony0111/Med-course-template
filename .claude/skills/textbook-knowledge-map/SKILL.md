# 教材知识点导航（按章增量）

开工前完整读取 `AGENTS.md`，遵守其中三条底线：`raw/` 只读、引用必须能回到原件页面、候选与已核对分离。

## 什么时候用

- 用户说「给第 X 章做知识点导航」「我要按知识点找教材」「这章有哪些知识点」。
- 不要在没有限定范围时整本生成。一次一章（或用户指定的小节范围），用不到的章节不建条目。

## 先找什么

| 需要的信息 | 去哪里找 |
|---|---|
| 章节名、印刷页、PDF 文件与 PDF 页、已知缺口 | `教材导航.md` |
| 教材正文 | `raw/md/<教材目录>/` 下的转换副本（MinerU `full.md` 等） |
| 版式、图表、表格的真实样子 | `raw/PDF/` 下的原件页面 |
| 已有编号与知识点名称 | `知识点.md` |

处理方式：

1. 在 MD 里先**搜索章节标题**，再读命中段落及前后上下文；不要整本读入。
2. 没有可用 MD 时：PDF 有文本层可以按页取文；扫描件没有文本层就**停下来报告用户**，不要据图片猜测文字内容。
3. 需要判断图表、生活史、流程、表格里的限定条件时回看原 PDF 页面，并在结果里注明「已回看原件」。

## 步骤

1. 读 `知识点.md`，取当前最大编号和已登记的知识点，避免重复条目，名称沿用已有写法。
2. 提取候选知识点：以教材的章节标题层级和正文知识单元为单位。
   - 判断标准：能否在课堂里被单独讲到、能被单独回查或考核的最小单元。
   - 不为每个小标题建条目，不把整段正文改写成条目。
3. 给新知识点分配 `KNN` 编号：**追加到当前最大编号之后**，不重排、不回收已删除编号。
4. 填 `教材章节`、`印刷页`、`PDF 页`：页码必须来自实际核对（MD 的页码映射或原 PDF 页面）。核对不到就**留空**，不按偏移量推算。
5. 写入 `知识点.md` 表格，状态一律先填 `候选`。
   - 只有确实回看了原件页面，才写 `已核对`，并在「别名/备注」写清依据，例如 `核对 PDF p.131`。
6. 更新 `教材导航.md` 的章节入口「知识点」列，只写范围（如 `K07–K15`），不抄知识点名称。
7. 向用户报告：本批清单（编号 + 名称 + 页码 + 状态）、没核对到的字段、发现的材料缺口。
8. 在 `log.md` 追加一行：`## [YYYY-MM-DD] ingest | 第 X 章知识点导航 — K07–K15（N 个，候选）`。

## 输出（只写进已有文件）

| 编号 | 知识点 | 教材章节 | 印刷页 | PDF 页 | 别名/备注 | 状态 |
|---|---|---|---|---|---|---|
| K07 | 心脏传导系统 | 第 3 章 | 123 | 131 | 核对 PDF p.131 | 已核对 |

## 硬规则

- 不修改、不移动 `raw/` 下任何文件；不修补自动生成的 `full.md`，纠错写在 `知识点.md` 备注或课堂页。
- 教材原文说法优先，不用自己的概括替换；别名写在备注列，不改名称。
- `印刷页` 与 `PDF 页` 分开填；不把 MD 行号当页码；`page_idx` 是否从 0 开始要核对，不能跨工具照搬。
- 不写「本章重点」「必考」之类的判断，也不写总结段落：导航只做定位。
- 范围外的章节不做占位条目。

## 完成后检查

- 编号是否连续、是否与已有编号冲突？
- 每个 `已核对` 是否写了核对依据？没核对的是否留空而不是猜填？
- 表格里是否混进了整段正文？有就删掉。
- `教材导航.md` 是否仍只有章节与 K 范围，没有重复知识点名称？
