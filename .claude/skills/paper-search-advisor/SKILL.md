# 论文检索智能推荐 Skill

## 文件构成

| 文件 | 什么时候读 |
|---|---|
| `system-prompt.md` | 执行任务前先读：分析框架四步与输出格式的完整定义 |
| `keywords-generator.md` | 生成关键词时读：分层关键词的推导规则 |
| `databases-config.json` | 推荐数据库时读：各库专业领域、覆盖范围、优势与适用场景 |
| `templates/search-keywords.json` | 需要结构化输出时读 |
| `templates/database-recommendation.json` | 需要结构化输出时读 |
| `examples/*.md` | 需要参考输出样式时读（医学 RAG、生物标志物两例） |

## 目标
根据研究主题或研究想法，自动：
1. 生成多角度、多层次的论文检索关键词
2. 推荐最适合的数据库优先级
3. 提供具体搜索策略和组合方式
## 适用场景
- 新研究项目启动
- 需要快速做文献综述
- 想系统地收集某领域论文
- 需要优化搜索策略
## 工作流程
1. 用户输入研究主题或想法
2. Skill 分析主题特征（学科、任务、应用场景等）
3. 生成分层关键词（基础词、扩展词、组合词、否定词）
4. 根据主题特征推荐数据库顺序
5. 输出搜索方案和建议
## 核心能力
- 主题分析
- 关键词生成
- 数据库匹配推荐
- 搜索策略制定
## 输入示例
- "医学领域的 RAG 系统"
- "深度学习在医学图像诊断中的应用"
- "自然语言处理在电子病历分析中的应用"
